# NewYearGarlandGuide

Краткая документация WPF-приложения «Новогодний гид по гирлянде».

## Назначение

Приложение `GuideWindow` показывает пошаговую инструкцию по украшению ёлки гирляндой. Поддерживаются три типа гирлянд:

| `garlandType` | Тип    |
|---------------|--------|
| `0`           | Нить   |
| `1`           | Сетка  |
| `2`           | Свечи  |

Инструкция состоит из 5 шагов. Для каждого шага отображаются:

- номер шага;
- заголовок;
- описание;
- изображение;
- прогресс-бар;
- кнопки «Назад» / «Далее».

---

## Класс `GuideWindow`

Окно пошагового гида.

### Конструктор

```csharp
public GuideWindow(int type)
```

Принимает тип гирлянды:

- `0` — нить;
- `1` — сетка;
- `2` — свечи.

После загрузки окна вызывается `UpdateStep(false)`, чтобы установить первый шаг без анимации.

### Поля

| Поле          | Назначение                     |
|---------------|--------------------------------|
| `currentStep` | Текущий шаг, по умолчанию `1`  |
| `totalSteps`  | Всего шагов — `5`              |
| `garlandType` | Тип гирлянды                   |

## Логика работы

### Переходы по шагам

- `Next_Click` — увеличивает `currentStep`, если это не последний шаг. На последнем шаге вызывает `Exit_Click`.
- `Prev_Click` — уменьшает `currentStep`, если шаг больше `1`.
- `Exit_Click` — создаёт и показывает `MainWindow`, затем закрывает текущее окно.

### Обновление шага

Метод `UpdateStep(bool animate)` выполняет:

1. Обновляет текст `ШАГ X ИЗ 5`.
2. Анимирует ширину `ProgressFill`:
   - если `animate == true` — плавно за 0.5 сек с `QuarticEase`;
   - иначе устанавливает ширину сразу.
3. Управляет кнопками:
   - `BackButton` скрыта на первом шаге;
   - `NextButton` меняет текст на «ЗАВЕРШИТЬ» на последнем шаге.
4. Выбирает набор текстов через `SetThreadText`, `SetNetText` или `SetCandleText`.
5. Загружает изображение по пути:

```
pack://application:,,,/Images/{prefix}{currentStep}.png
```

Префиксы изображений:

- нить — `Thread`;
- сетка — `Net`;
- свечи — `Candle`.

Примеры:

```
Images/Thread1.png
Images/Net3.png
Images/Candle5.png
```

Если изображение не найдено, `StepImage.Source` становится `null`, исключение подавляется.

---

## Структура ресурсов

В проекте должна быть папка `Images`:

```
Images/
├── Thread1.png ... Thread5.png
├── Net1.png ... Net5.png
└── Candle1.png ... Candle5.png
```

Для изображений желательно установить **Build Action = Resource**, иначе `pack://application:,,,/...` может не найти файл.

---

## Пример вызова

Из главного окна при выборе типа гирлянды:

```csharp
var guide = new GuideWindow(1); // 1 — сетка
guide.Show();
this.Close();
```

---

## Примечания

- Анимация прогресс-бара зависит от `ActualWidth`, поэтому первый вызов делается после `Loaded`.
- `ProgressFill` — это `Rectangle`, у которого анимируется `WidthProperty`.
- `Exit_Click` создаёт новый экземпляр `MainWindow`. Если нужно возвращаться к уже открытому главному окну, логику стоит изменить.
